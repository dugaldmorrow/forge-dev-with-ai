
# Presentation Format

This file explains the formatting and conventions used in [Presentation.html](./Presentation.html) so that it is consistently formatted and interpreted.


* Each slide in the presentation has a unique title.
* The presentation slides are contained in the Reveal.js `<div class="slides">` container.
* Each slide in the presentation is represented by a top-level `<section>` element.
* Each slide title is written as an `<h2>` or `<h3>` element inside the relevant `<section>`.
* Each slide has speaker notes.
* Each slide's speaker notes are contained in an `<aside class="notes">` element inside the relevant slide `<section>`.
* Appendix slides may appear after the closing slide and should be clearly labelled as appendix material.
