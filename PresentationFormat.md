
# Presentation Format

this file explains the formatting and conventions used in [Presentation.md](./Presentation.md) so that it is consistently formatted and interpreted.


* Each slide in the presentation has a unique title.
* The presentation slides are contained in a level 2 section named "Slides".
* Each slide in the presentation is detailed in a level 3 section within the Slides section where the title of the section is the title of the slide.
* Each slide in the presentation has speaker notes.
* Each slide's speaker notes are contained in HTML <details> and <summary> tags within a level 4 section named "Speaker notes" in the relevant slide section.
