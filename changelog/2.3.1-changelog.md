## Summary

Corrected the Forge AI Plugin installation story so the deck presents a plugin-first path where supported, a clear manual fallback for Rovo Dev and unsupported hosts, and accurate component naming for bundled skills and MCP servers.

## Changes

### Presentation (Presentation.html)

- **Slide 19 — Forge AI Plugin**: Changed the table from a skills-only list to a component table that separates Forge skills from the Forge MCP Server and ADS MCP Server.
- **Slide 19 speaker notes**: Corrected host-specific install guidance: Claude Code, Cursor, Gemini CLI, and GitHub Copilot use plugin/extension install paths, while Rovo Dev and unsupported hosts use the manual `npx skills add atlassian/forge-skills` fallback plus MCP configuration.
- **Slide 19 speaker notes**: Removed Codex CLI from the current plugin-aware host list and noted that OpenAI Codex support is listed as coming soon in the Forge Skills repo.
- **Slide 20 — npx skills**: Reframed `npx skills` as the manual fallback rather than the primary installation path.
- **Slide 33 speaker notes**: Updated the ideal setup narration to reference the Forge AI Plugin where supported, or the manual forge-skills fallback where not supported.
- **Slide 38 and Slide 39b**: Updated Level 2 adoption guidance to install the Forge AI Plugin where supported, with `npx skills add atlassian/forge-skills` plus manual MCP config as the fallback.
- **Slide 44 — Appendix sources**: Added direct links to the Forge AI Plugin documentation and the `atlassian/forge-skills` repository.
