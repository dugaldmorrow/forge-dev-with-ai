# Changelog: 1.0.0

**Date:** 23-May-2026, 15:09 AEST  
**Previous version:** N/A (initial version)  
**Change type:** MAJOR

## Summary

Initial creation of the Forge Dev with AI Research project. This version establishes the foundational project structure including the agent configuration, presentation scaffolding, and agent skills for commit and changelog management.

## Changes

### Documentation

- **AGENTS.md**: Initial agent configuration file defining the research assistant persona, project scope, key references, and boundaries. Covers AI software development agents, IDE classifications, MCP servers, agent skills, and Atlassian-internal tools.
- **Presentation.md**: Initial (empty) presentation file to be populated with research findings.
- **PresentationFormat.md**: Defines the formatting and conventions for `Presentation.md`, including slide structure, speaker notes format using HTML `<details>`/`<summary>` tags, and heading hierarchy.
- **Metadata.md**: Initial metadata file recording the project version (1.0.0) and date.

### Skills

- **.agents/skills/commit/SKILL.md**: Agent skill defining the procedure for committing changes to git, including changelog verification, validation, staging, commit message format, and confirmation steps.
- **.agents/skills/changelog/SKILL.md**: Agent skill defining how to maintain the project changelog and `Metadata.md`, including semantic versioning rules, changelog file format, and update rules.
