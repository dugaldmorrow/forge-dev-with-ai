## Summary

Added a new FAQ entry (Q13c) addressing how an AI agent chooses between the Atlassian Rovo MCP Server and the TWG CLI when both are configured. The answer explains that agent selection is non-deterministic without explicit instruction, cites official guidance recommending explicit surface specification, and outlines four practical mitigation approaches.

## Changes

### Documentation

- **faq.html**: Added FAQ Q13c — "If an AI agent has been configured to use both the Atlassian Rovo MCP Server and the TWG CLI, how does it choose which to use?" Covers non-deterministic selection behaviour, official guidance to explicitly name the surface, and four recommended approaches: pick one per environment, explicit prompt instructions, set defaults in agent config, and use separate profiles.
