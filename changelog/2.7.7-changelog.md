# Changelog: 2.7.7

**Date:** 7-Jun-2026, 11:43 AEST  
**Previous version:** 2.7.6  
**Change type:** PATCH

## Summary

Fixed slide titles not being horizontally centred. The existing `text-align: left` rule on slide sections was cascading into headings; added an explicit `text-align: center` override to the h1/h2/h3 rule so titles render centred while body content remains left-aligned.

## Changes

### Presentation

- **Presentation.html**: Added `text-align: center` to the `.reveal h1, .reveal h2, .reveal h3` CSS rule to override the section-level `text-align: left` and restore centred slide titles.
