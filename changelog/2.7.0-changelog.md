# Changelog: 2.7.0

**Date:** 7-Jun-2026, 09:55 AEST  
**Previous version:** 2.6.10  
**Change type:** MINOR

## Summary

Added a new slide 5c "Increasing levels of abstraction" immediately before the Four categories slide. This reframes the classification of AI coding tools around abstraction level (what you give the AI) rather than autonomy alone — a more technically precise and developer-familiar framing. The Four categories slide (slide 6) was retained but its Description column was updated to describe what each tool looks like rather than repeating the abstraction framing.

## Changes

### Presentation

- **Presentation.html** (new slide 5c): Added "Increasing levels of abstraction" slide with a two-column table mapping abstraction levels (Token/line, Task/file, Goal/feature, Intent/product) to what you give the AI, with category names shown in parentheses. Detailed speaker notes explain the abstraction ladder analogy and transition to slide 6.
- **Presentation.html** (slide 6, Description column): Updated all four descriptions to describe the *form factor* of each category rather than repeating the abstraction framing:
  - AI Coding Assistants: "Plugin in your existing editor — lowest switching cost"
  - AI-Native IDEs: "Full IDE rebuilt around AI — agent mode is a first-class citizen, not a plugin"
  - AI Dev Agents: "Terminal or web — you hand off a goal and review the result"
  - Autonomous Dev Platforms: "Cloud platform — describe intent, the platform builds and deploys"
