# Changelog: 1.2.7

**Date:** 25-May-2026, 15:27 AEST  
**Previous version:** 1.2.6  
**Change type:** MINOR

## Summary

Added two new slides: one explaining the `atlassian/forge-skills` GitHub repository (Atlassian's official skill bundle), and one explaining how `npx skills` works as a package manager for agent skills — including the install flow, the manual update requirement, the auto-update SessionStart hook pattern, and team lockfile consistency. Also corrected the install command on the forge-skills slide from the incorrect `npx forge-skills install` to the correct `npx skills add atlassian/forge-skills`.

## Changes

### Documentation

- **Presentation.md**: Added new slide "`npx skills` is the package manager for agent skills — install once, update manually to stay current" positioned between the `atlassian/forge-skills` slide and the "MCP servers give agents live capabilities" slide. Covers:
  - What `npx skills add atlassian/forge-skills` actually does step-by-step (download, agent detection, file placement, lock file creation)
  - Agent directory locations: universal `.agents/skills/`, Claude Code `.claude/skills/`, Antigravity `.agent/skills/`
  - Skills are a static snapshot — they do not auto-update
  - Update commands: `npx skills check`, `npx skills update`, `npx skills update forge-skills`
  - Auto-update pattern via Claude Code `SessionStart` hook (zero token cost)
  - Team consistency via `skills-lock.json` and `npx skills experimental_install`
  - Speaker notes covering the npm mental model, static vs. live distinction, lockfile CI use, SessionStart hook, and the common "stale skills" confusion

- **Metadata.md**: Updated version from 1.2.6 to 1.2.7 and date to 25-May-2026, 15:27 AEST.
