# Changelog: 2.0.0

**Date:** 2-Jun-2026, 23:44 AEST  
**Previous version:** 1.9.1  
**Change type:** MAJOR

## Summary

The presentation format has been migrated from Markdown (`Presentation.md`) to a fully interactive reveal.js HTML presentation (`Presentation.html`). `Presentation.md` has been deleted. Illustration design specs previously embedded in `Presentation.md` as `<details>` blocks have been extracted into a standalone `IllustrationSpecs.md` file. The `reveal.js-master/` library has been added to the workspace to support the HTML presentation.

## Changes

### Presentation

- **Presentation.html**: New file — all 42 slides from `Presentation.md` converted to a reveal.js HTML presentation, including speaker notes in `<aside class="notes">` elements, syntax-highlighted code blocks, and a black theme. Depends on `reveal.js-master/`.
- **Presentation.md**: Deleted — content fully migrated to `Presentation.html` and `IllustrationSpecs.md`.

### Documentation

- **IllustrationSpecs.md**: New file — the 5 illustration/diagram design specs extracted from `Presentation.md`, each annotated with the slide title and slide number they relate to.

### Dependencies

- **reveal.js-master/**: Added — the reveal.js library (local copy) required by `Presentation.html`.
