# Changelog: 1.5.1

**Date:** 27-May-2026, 07:21 AEST  
**Previous version:** 1.5.0  
**Change type:** PATCH

## Summary

Added the Atlassian Design System (ADS) MCP Server (`@atlaskit/ads-mcp`) to the MCP servers slide in the presentation. The server was added to the "App development" table and its details were included in the slide's speaker notes, encouraging developers to use it when building Custom UI Forge apps to ensure generated UI code aligns with the Atlassian Design System.

## Changes

### Documentation

- **Presentation.md**: Added `🎨 ADS MCP Server` row to the "App development" MCP servers table on the "Two types of MCP servers power Forge development" slide, positioned immediately after the Forge MCP Server row. Capabilities described as: ADS components, design tokens, icons, and accessibility guidelines — ensures generated UI code matches the Atlassian Design System.
- **Presentation.md**: Added `ADS MCP Server` entry to the speaker notes for the same slide, including the npm package name (`@atlaskit/ads-mcp`), both local (`npx`) and remote (`https://mcp.atlassian.com/v1/ads/public/mcp`) config options, key capabilities (component catalogs, design tokens, icons, WCAG 2.1 AA accessibility analysis), and guidance on when it is most valuable (Custom UI apps).
