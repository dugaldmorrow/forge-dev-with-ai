# Changelog: 2.2.3

**Date:** 2-Jun-2026, 15:53 AEST  
**Previous version:** 2.2.2  
**Change type:** MINOR

## Summary

Added a standalone FAQ page (`faq.html`) containing 39 anticipated audience questions across 8 themed sections, each as a collapsible show/hide entry. Also audited and revised all uses of the word "autonomous" in `Presentation.html`, removing instances that were redundant (implied by "agent") or misleading (overstating the independence of tools like GitHub Copilot), while retaining the six instances that carry genuine definitional, structural, or attributed meaning.

## Changes

### Presentation

- **`Presentation.html`**: Revised 6 uses of "autonomous"/"autonomy":

  - Slide 11 Copilot blockquote: "autonomous PR creation, agentic code review" → "agentic PR creation and code review" (misleading — overstated Copilot's independence)
  - Slide 11 speaker note: "into autonomous agent mode and PR creation" → "into agent mode and agentic PR creation" (same reason)
  - Slide 38 adoption level label: "3 — Autonomous Agent" → "3 — Agentic Workflow" (redundant and sets unrealistic expectations)
  - Slide 38 speaker note: "go all-in on autonomous agents" → "go all-in on agents" (redundant)
  - Slide 41 landscape summary table: "Autonomous multi-step coding tasks" → "Multi-step coding tasks" (redundant)

### New Files

- **`faq.html`**: New standalone FAQ page containing 39 anticipated audience questions across 8 themed sections (Agents vs Autocomplete, MCP Servers, Agent Skills, Forge + AI Development, App Studio, Security/Privacy/Cost, Getting Started, Future). Each question uses a native HTML `<details>`/`<summary>` element — collapsed by default, no JavaScript required. Styled with a dark theme consistent with the presentation aesthetic, with green tip callouts and amber warning callouts. Fully self-contained with no external dependencies.
