# Changelog: 1.4.1

**Date:** 25-May-2026, 23:31 AEST  
**Previous version:** 1.4.0  
**Change type:** MINOR

## Summary

Added `PresentationMetadata.md` — a new reference file documenting the audience profile and presentation preferences for `Presentation.md`. Covers presenter details, audience technical experience range, tone, depth preferences, slide content conventions, pacing, content priorities, key messages, and known audience concerns to address.

## Changes

### Documentation

- **PresentationMetadata.md**: New file created. Documents the audience profile (varied technical experience, Forge-interested developers), presentation preferences (technical where necessary, honest and balanced, action titles, detailed speaker notes), pacing guidance (45–60 minute session, Q&A before final slide), the three key messages (MCP = connection, Skills = knowledge, Forge = platform), content priorities, and known audience concerns with guidance on how to address each.
