# Changelog: 1.2.6

**Date:** 25-May-2026, 15:15 AEST  
**Previous version:** 1.2.5  
**Change type:** MINOR

## Summary

Added a new slide covering the `atlassian/forge-skills` GitHub repository — Atlassian's official skill bundle for Forge development. The slide is positioned immediately after the "Agent skills are reusable instruction sets" intro slide, making it the concrete implementation example that follows the conceptual introduction.

## Changes

### Documentation

- **Presentation.md**: Added new slide "`atlassian/forge-skills` is Atlassian's official skill bundle — scaffold, review, debug, and connect in one install" (positioned after the Agent Skills intro slide). Covers:
  - Overview of the Forge Skills Plugin: four bundled skills (Forge App Builder, Forge App Review, Forge Debugger, Forge Connector) plus MCP-backed tooling
  - Forge Connector skill — builds `graph:connector` apps that ingest external data into Atlassian's Teamwork Graph for Rovo Search and Rovo Chat
  - Bundled MCP tooling: up-to-date Forge docs, template registries, module config, manifest syntax, UI Kit guides, and Atlassian Design System lookup
  - Install command: `npx forge-skills install`
  - Compatibility note: works with Rovo Dev, Claude Code, Cursor, GitHub Copilot, and Codex CLI
  - Speaker notes with: official Atlassian provenance, four-skill summary, MCP bundling detail, Rovo Dev manual install note, quick-check prompts for post-install verification, and Forge Connector use case highlight

- **Metadata.md**: Updated version from 1.2.5 to 1.2.6 and date to 25-May-2026, 15:15 AEST.

## Corrections

- **Presentation.md** — Fixed incorrect install command on the `atlassian/forge-skills` slide. `npx forge-skills install` was replaced with the correct command `npx skills add atlassian/forge-skills` (per the official README). Added the Rovo Dev manual install path (`acli rovodev mcp`) as a code comment for completeness.
