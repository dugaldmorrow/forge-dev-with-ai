- **Slide 22 (Agents choose whether to invoke MCP or skills)**: Replaced verbose ASCII code block with a clean two-row table and blockquote.

- **Slide 23 (rewritten)**: Replaced antipattern "Prompt explicitly" slide (with per-prompt explicit instructions) with a five-technique reliability table ordered by effectiveness:

- **Slide 23 title**: Updated from "Four techniques" to "Five techniques" after adding domain terminology row.
