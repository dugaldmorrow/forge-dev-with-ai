# Changelog: 2.2.1

**Date:** 2-Jun-2026, 15:25 AEST  
**Previous version:** 2.2.0  
**Change type:** PATCH

## Summary

Restructured all 45 speaker note blocks in `Presentation.html` to follow a consistent two-part format: spoken talking points first as natural prose paragraph(s), followed by a bullet list of background information not intended to be spoken during the presentation. This separates what the presenter says from reference material available in the notes panel.

## Changes

### Presentation

- **`Presentation.html`**: Rewrote all 45 `<aside class="notes">` blocks. Each now opens with one or more `<p>` tags containing the key spoken talking points in natural language, followed by a `<ul>` of background notes (data sources, gotchas, additional context, transition cues for co-presenters). Slides with only a brief spoken cue (e.g. agenda slide, transition-only slides) use a single `<p>` with no background list. Verified programmatically that no `<ul>` precedes a `<p>` in any block.
