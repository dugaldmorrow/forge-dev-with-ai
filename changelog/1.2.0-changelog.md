# Changelog: 1.2.0

**Date:** 25-May-2026, 08:20 AEST  
**Previous version:** 1.1.6  
**Change type:** MINOR

## Summary

Added a new `presentation-best-practices` agent skill synthesised from thorough research across authoritative public sources (MIT, McKinsey/Minto, Penn State/Alley, Duarte) and Atlassian's internal AI slides standards from the Malleable Content team on hello.atlassian.net (2026). The skill guides AI agents when creating, reviewing, or improving slide-based presentations.

## Changes

### Skills

- **.agents/skills/presentation-best-practices/SKILL.md**: New skill covering:
  - Narrative structure: Pyramid Principle (top-down, answer first), SCQA framework (Situation/Complication/Question/Answer), and presentation arc (hook → context → body → summary → CTA → Q&A → close)
  - Slide content principles: one idea per slide, action titles vs topic labels, minimise text, the "So What?" test, the Glance Test, grounded claims
  - Visual design: whitespace, colour restraint (2–3 colours, 4.5:1 contrast), sans-serif typography, visual hierarchy, consistency
  - Data visualisation: charts vs tables decision framework, simplification, honesty in data representation
  - Speaker notes: what to include (talking points, stats, transitions, prompts), what to avoid (verbatim transcripts), target length (3–8 bullets)
  - Pacing and length: 1 slide/minute rule of thumb, 120–150 wpm speaking pace, Kawasaki 10/20/30 rule
  - Opening and closing: first-60-seconds hooks, rule of three summary, CTA placement, Q&A before final slide
  - Quality checks: title read-through test, So What? test, Glance Test, faithfulness check, accessibility check
  - Atlassian-specific standards: tone ("professional and respectful; assume intelligent, time-constrained viewers"), active voice, markdown format conventions from PresentationFormat.md
