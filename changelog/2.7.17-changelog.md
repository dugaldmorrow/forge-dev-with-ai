# Changelog: 2.7.17

**Date:** 8-Jun-2026, 09:13 AEST  
**Previous version:** 2.7.16  
**Change type:** PATCH

## Summary

Fixed the "Skills = Local; MCP = Remote" slide (SLIDE 21b) so that blue and green text colours appear immediately when each bullet animates in, without requiring a second arrow-key press. Previously the colours were applied via `class="fragment highlight-blue/green"` on the `<span>` elements, which required a separate fragment step to activate. Replaced with inline `style="color:..."` using the same colour values (#1b91ff for blue, #17ff2e for green), so the colour is always visible as soon as the `<li>` fragment appears.

## Changes

### Presentation

- **Presentation.html** (SLIDE 21b): Replaced `class="fragment highlight-blue"` and `class="fragment highlight-green"` on `<span>` elements with equivalent inline `style="color:#1b91ff"` and `style="color:#17ff2e"` respectively. The `class="fragment"` on each `<li>` is retained so bullets still appear one at a time on each arrow-key press.
