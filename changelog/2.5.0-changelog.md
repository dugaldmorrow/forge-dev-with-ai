# Changelog: 2.5.0

**Date:** 3-Jun-2026, 19:22 AEST  
**Previous version:** 2.4.5  
**Change type:** MINOR

## Summary

Added a new quiz agent skill that tests the user's understanding of the presentation content. The skill includes a 20-question bank covering all major themes, a 24-hour cooldown cadence system backed by a JSON state file, and topic-rotation logic to ensure variety across sessions. AGENTS.md was updated to document the skill and its opt-in loading behaviour.

## Changes

### Skills

- **`.agents/skills/quiz/SKILL.md`**: New skill file. Defines the quiz skill with a 20-question bank derived from the presentation slides, cadence rules (24-hour cooldown, state-file-backed tracking, topic rotation), question format, feedback guidelines, and rules for respectful, non-intrusive delivery.
- **`.agents/skills/quiz/quiz-state.json`**: New state file. Tracks `last_asked_iso`, `last_asked_id`, and `asked_ids` so the skill can enforce the cooldown and avoid repeating questions. Initialised to a blank state.

### Documentation

- **`AGENTS.md`**: Added a "Quiz Skill" subsection under "Skills" explaining when to load the skill (opt-in only), how the cadence works, and the 24-hour cooldown rule.
- **`Metadata.md`**: Bumped version to 2.5.0 and updated date.
