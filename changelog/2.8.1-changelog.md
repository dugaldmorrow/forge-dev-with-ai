## Summary

Added a new FAQ entry (Q13b) clarifying the relationship between the Teamwork Graph CLI and the Atlassian Rovo MCP Server. The answer corrects a common misconception that one tool is primary over the other, and reframes the distinction accurately as a runtime/workflow pattern choice rather than a data-access hierarchy. Both tools access Atlassian data and the Teamwork Graph; the choice depends on whether the agent uses MCP protocol or a terminal/shell runtime.

## Changes

### Documentation

- **faq.html**: Added FAQ Q13b — "Are both the Teamwork Graph CLI and Atlassian Rovo MCP Server both for connecting to Atlassian data?" The answer clarifies that both tools are complementary (not ranked), both can access the Teamwork Graph, TWG CLI covers 15+ Atlassian products, and the real distinction is runtime: MCP protocol clients use the Rovo MCP Server; terminal/shell agents use the TWG CLI.
